# PDR UI Skills

Claude skills for building PDR.cloud user interfaces.

| Skill | Description |
|---|---|
| [`pdr-design-system`](pdr-design-system/) | PDR.cloud Figma Design System → Angular Material M3: guardrails, design tokens, theming rules, and one doc per Figma component page (MD3 + PDR) |

## Install

- **Claude Code:** copy a skill folder into `.claude/skills/` of your project (or `~/.claude/skills/`).
- **Claude.ai:** zip a skill folder and upload it under Settings → Capabilities → Skills.
