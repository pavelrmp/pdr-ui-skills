# Tokens

One file per token category, generated from `../../tokens.json` (the machine-readable source) and the Figma **⚛️ Design Tokens** page.

| File | Contents |
|---|---|
| `colors.md` | M3 color roles (light/dark), surface usage, semantic + additional PDR colors, reference palette |
| `typography.md` | Typefaces, type scale with Figma names and PDR usage, PDR additions, accessibility modes |
| `spacing.md` | Spacing scale and usage; dialog sizes and breakpoints (pointers) |
| `shape.md` | Corner radius scale and which components use which radius |
| `elevation.md` | Shadow levels 0–5 (light/dark) and which components use which level |
| `state-layers.md` | Hover / focus / pressed / dragged opacities and PDR helpers |
| `motion.md` | Motion guidance (no Figma tokens yet) |

Breakpoints and grids: `../foundations/grids-breakpoints.md`. Icons: `../foundations/icons.md`.
